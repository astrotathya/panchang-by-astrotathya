# WordPress.org listing assets

Not part of the plugin zip (bin/build-zip.sh leaves this folder out). On WordPress.org they go in
the SVN `assets/` folder, beside `trunk/` and `tags/`.

| File | Use |
|---|---|
| `icon-128x128.png`, `icon-256x256.png` | Plugin icon in search results and on the plugin page |
| `banner-772x250.png`, `banner-1544x500.png` | Plugin page header (normal and high-DPI) |
| `screenshot-1.png` … `screenshot-4.png` | Screenshots; captions are in readme.txt "Screenshots" |

Screenshots were taken on 21 Oct 2026 from a local WordPress 7.1.3 test site with this plugin
installed from its release zip; the widgets show live data from astrotathya.com for that day.
The site name and temple text in them are placeholders ("Example Mandir Site", "Our Community
Mandir"), not a real organisation.
